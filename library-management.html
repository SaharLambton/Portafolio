// 01 · LA MISIÓN

La misión

Una aplicación que simula la gestión de una biblioteca. Permite registrar libros y clientes, prestar un libro solo si está disponible y devolverlo solo si ese cliente lo tiene. Cada operación está cubierta con pruebas unitarias en Jest que se ejecutan solas en GitHub cada vez que se sube un cambio.

// QUÉ SE CONSTRUYÓ

Funcionalidades

  • Registro de libros y clientes
  • Búsqueda por ID
  • Préstamo solo si el libro está disponible
  • Devolución solo si el cliente tiene el libro
  • Mensajes claros de éxito o error

Arquitectura

  • Modelos: Book y Customer
  • Servicio Bookstore con toda la lógica
  • TypeScript compilado a JavaScript en dist/

Calidad

  • Pruebas de agregar, prestar y devolver libros
  • Reporte de cobertura con Jest
  • GitHub Actions en cada push y pull request a main
  • Caché de dependencias y reporte guardado como artefacto
