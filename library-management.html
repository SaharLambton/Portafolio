// 01 · LA MISIÓN

La misión

Library Management simula la operación de una biblioteca: registro de libros y clientes, préstamos y devoluciones. El reto principal era garantizar que el sistema nunca quedara en un estado inconsistente —por ejemplo, prestar un libro que ya está prestado o recibir la devolución de un libro que el cliente no tiene—. Para lograrlo apliqué programación orientada a objetos, cubrí cada operación con pruebas unitarias en Jest y configuré GitHub Actions para que las pruebas se ejecuten automáticamente con cada cambio. Proyecto desarrollado en el programa Computer Programmer de Lambton College, en Ontario (Canadá), bajo estándares profesionales de desarrollo, documentación y control de versiones.

// CALIDAD

Cómo se garantiza que funcione

01

Reglas de negocio claras

Un libro solo se presta si está disponible y solo se devuelve si el cliente lo tiene, con mensajes claros de éxito o error.

02

Pruebas por operación

Pruebas unitarias para agregar, prestar y devolver libros, que verifican tanto la respuesta como el estado final.

03

Código fuente y compilado

Las pruebas se ejecutan sobre el código TypeScript y sobre el JavaScript compilado, para asegurar que la versión final se comporte igual.

04

Integración continua

GitHub Actions ejecuta las pruebas en cada push y pull request, guarda en caché las dependencias y conserva el reporte de cobertura.
