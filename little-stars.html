📋 Resumen del Proyecto

Proyecto personal de práctica desarrollado para reforzar y perfeccionar habilidades de frontend web. Little Stars es un sitio web moderno para una tienda ficticia de ropa infantil que demuestra el dominio de HTML5 semántico, CSS3 avanzado y principios de diseño responsive. El proyecto simula una experiencia real de e-commerce con énfasis en la estética visual y usabilidad.

🎯 Objetivo

Practicar y reforzar habilidades de maquetación web, diseño responsive y crear una interfaz atractiva para e-commerce infantil.

⏱️ Duración

2 días de desarrollo intensivo, enfocados en diseño visual, estructura HTML y estilos CSS.

💥 Rol

Desarrolladora Frontend - Diseño de interfaz, maquetación HTML/CSS, diseño responsive y arquitectura de componentes.

✨ Características Implementadas

  • Página de inicio (Home) con hero section atractiva y llamada a la acción
  • Sistema de navegación limpio y funcional
  • Sección de categorías populares (Niñas, Niños, Bebés)
  • Página de tienda con grid de productos
  • Sistema de filtros por categoría y talla (interfaz diseñada)
  • Barra de búsqueda de productos
  • Cards de productos con imagen, título, precio y botón de acción
  • Sección "Por qué elegirnos" con íconos Font Awesome
  • Footer informativo con enlaces rápidos y datos de contacto
  • Diseño completamente responsive para todos los dispositivos

🛠️ Tecnologías y Técnicas

HTML5 Semántico: Uso correcto de etiquetas semánticas (nav, header, section, footer) para estructura clara y accesible

CSS3 Avanzado: Grid y Flexbox para layouts modernos, transiciones suaves, efectos hover y diseño de componentes reutilizables

Font Awesome: Integración de iconografía profesional para mejorar la experiencia visual

Responsive Design: Técnicas de diseño adaptativo para garantizar funcionalidad en móviles, tablets y desktop

Arquitectura CSS: Organización de estilos en un archivo externo centralizado (styles.css)

🎨 Elementos de Diseño

Hero Section

Sección principal impactante con título llamativo, descripción de colección actual y botón CTA prominente para dirigir a la tienda.

Categorías Visuales

Grid de tarjetas con imágenes para Niñas, Niños y Bebés, facilitando la navegación por segmento de edad.

Sistema de Filtros

Selectores dropdown para categoría y rango de talla, más campo de búsqueda textual para encontrar productos específicos.

Product Cards

Tarjetas de producto elegantes con imagen destacada, nombre del artículo, precio visible y botón de acción "Añadir al carrito".

Sección de Valor

Destacados de beneficios clave: Calidad Premium, Envío Rápido y Devolución Gratuita con íconos ilustrativos.

Footer Informativo

Pie de página estructurado con información de la marca, enlaces rápidos y datos de contacto organizados en columnas.

👗 Categorías de Productos

  • Niñas: Vestidos, conjuntos, accesorios diseñados específicamente para niñas
  • Niños: Ropa deportiva, casual y formal para niños
  • Bebés: Prendas especiales para bebés de 0-12 meses
  • Rangos de Talla: 0-3 meses, 3-6 meses, 6-12 meses, 1-2 años

🎯 Propuesta de Valor

Calidad Premium

Énfasis en materiales suaves y duraderos, apropiados para la piel sensible de los niños.

Envío Rápido

Promesa de entrega en 24-48 horas para conveniencia de los padres.

Devolución Gratuita

Garantía de 30 días para generar confianza en las compras online.

💡 Aprendizajes y Práctica

  • Refuerzo de habilidades de maquetación con CSS Grid y Flexbox
  • Práctica de diseño de componentes reutilizables (cards, botones, navegación)
  • Implementación de diseño responsive con enfoque mobile-first
  • Uso efectivo de espaciado, tipografía y jerarquía visual
  • Integración de librerías externas (Font Awesome) de forma eficiente
  • Creación de estructura HTML semántica y accesible
  • Diseño de interfaz limpia y moderna para e-commerce

📊 Estructura de Archivos

  • index.html: Página principal con hero, categorías y sección de valor
  • tienda.html: Página de catálogo con filtros y productos
  • styles.css: Hoja de estilos centralizada para todo el sitio
  • img/: Carpeta de imágenes organizadas (niñas.jpg, niños.jpg, bebés.jpg, productos)
  • Font Awesome CDN: Iconografía profesional integrada vía CDN

🔮 Características Planificadas (No Implementadas)

Como proyecto de práctica en fase inicial, el sitio se enfoca en diseño y maquetación. Las siguientes funcionalidades están diseñadas visualmente pero no implementadas funcionalmente:

  • Funcionalidad JavaScript para filtros dinámicos
  • Sistema de carrito de compras con almacenamiento local
  • Backend para gestión de productos y pedidos
  • Base de datos para catálogo de productos
  • Páginas adicionales (Colecciones, Contacto, Sobre Nosotros)
  • Sistema de pago integrado

🎨 Paleta de Colores y Diseño

El diseño visual utiliza una paleta suave y amigable apropiada para un público infantil, con colores pasteles y tonos cálidos que transmiten confianza y calidez. La tipografía es clara y legible, con jerarquías bien definidas para facilitar la navegación.
