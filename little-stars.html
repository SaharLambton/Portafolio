// 01 · LA MISIÓN

La misión

Un sitio para una tienda ficticia de ropa infantil, creado para practicar maquetación y diseño responsive. Simula una experiencia real de e-commerce con énfasis en la estética y la usabilidad: colores pastel, tarjetas de producto y navegación por edades.

// QUÉ SE CONSTRUYÓ

02

Lo que incluye

  • Hero con llamado a la acción
  • Categorías: niñas, niños y bebés
  • Tienda con grid de productos y buscador
  • Filtros por categoría y talla
  • Sección "Por qué elegirnos" con íconos

Lo que practiqué

  • CSS Grid y Flexbox
  • Componentes reutilizables: tarjetas y botones
  • Diseño mobile-first
  • HTML semántico y accesible

Próximos pasos

  • Filtros dinámicos con JavaScript
  • Carrito con almacenamiento local
  • Backend y base de datos de productos
  • Pasarela de pagos
