// 01 · LA MISIÓN

La misión

Un modelo orientado a objetos de una granja inteligente. Cada parte del campo es una clase: un sensor que mide la humedad, un pronóstico del clima, un sistema de riego, drones y un detector de enfermedades. Un controlador combina esos datos para decidir cuándo regar. El proyecto se publicó como paquete en npm, así que cualquiera puede instalarlo.

// QUÉ SE CONSTRUYÓ

Componentes del sistema

  • Sensor: lee el tipo, la ubicación y el valor medido
  • Pronóstico del clima que decide si conviene regar
  • Controlador de riego que une sensor, clima y sistema de riego
  • Drones que se envían a cada zona del campo
  • Detector de enfermedades en las plantas

Lo que practiqué

  • Clases con propiedades públicas y privadas en TypeScript
  • Inyección de dependencias en el controlador
  • Compilación de TypeScript a JavaScript con tsc
  • Publicación de un paquete en npm con sus tipos
