// 01 · LA MISIÓN

La misión

Smart Agriculture propone una base de software para optimizar la producción agrícola mediante tecnología y datos. El sistema modela los componentes de una finca inteligente —sensores ambientales, pronóstico del clima, sistema de riego, drones de vigilancia y detección de enfermedades— y un controlador que combina la información de los sensores con el clima para decidir cuándo regar. Lo desarrollé en equipo con Julián Casilimas: planificamos el trabajo, documentamos las decisiones de diseño y publicamos el resultado como paquete en npm para que pueda instalarse y reutilizarse en otros proyectos. Proyecto desarrollado en el programa Computer Programmer de Lambton College, en Ontario (Canadá), bajo estándares profesionales de desarrollo, documentación y control de versiones.

// QUÉ SE CONSTRUYÓ

Principios de diseño

  • Encapsulamiento: cada clase expone una interfaz clara
  • Abstracción de elementos reales del campo
  • Inyección de dependencias en el controlador de riego
  • Componentes desacoplados y fáciles de ampliar

Trabajo en equipo

  • Planificación de tareas en Trello
  • Documentación de las decisiones de diseño orientado a objetos
  • README con instalación y ejemplo de uso
  • Control de versiones en GitHub

// ARQUITECTURA

Los componentes de una finca inteligente

Cada elemento del campo se representa como una clase con una responsabilidad única, lo que permite incorporar nuevos sensores o tecnologías sin modificar el resto del sistema.

01

Sensor

Ofrece una interfaz estándar para leer el tipo, la ubicación y el valor de cada medición, como la humedad del suelo.

02

Pronóstico del clima

Aporta la información meteorológica que determina si las condiciones son adecuadas para regar.

03

Controlador de riego

Combina los datos del sensor y del clima para decidir si activa el sistema de riego.

04

Sistema de riego

Ejecuta el riego cuando el controlador lo indica.

05

Drones

Se desplazan a las zonas del campo para tareas de vigilancia y recolección de datos.

06

Detector de enfermedades

Analiza los cultivos en busca de posibles enfermedades en las plantas.
