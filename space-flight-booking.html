// 01 · LA MISIÓN

La misión

El backend de una agencia que vende vuelos a Marte. Antes de reservar, el sistema verifica que el pasajero sea mayor de edad y tenga certificado médico; si hay cupo, crea la reserva, descuenta el asiento y registra el pago. Además de la lógica, el proyecto prepara todo el ciclo DevOps: pruebas automáticas, un contenedor Docker y un pipeline que construye y publica la imagen.

// QUÉ SE CONSTRUYÓ

Lógica de negocio

  • Verificación médica: mayor de 18 y con certificado
  • Reservas con control de cupos
  • Al cancelar, el asiento se libera
  • Pagos registrados por reserva
  • Estados con enums: confirmada, pendiente, cancelada

Calidad

  • Pruebas en Jest para reservas, pagos y verificación médica
  • Registro de eventos con fecha y hora
  • Entidades y servicios separados

DevOps

  • Dockerfile que compila TypeScript y arranca la app
  • Pipeline en GitHub Actions sobre la rama develop
  • Instala, prueba y compila en cada push
  • Publica la imagen en Docker Hub con credenciales en secrets
