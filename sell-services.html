// 01 · LA MISIÓN

La misión

Una plataforma completa para comercializar productos y servicios gráficos personalizados (camisetas, cuadernos, termos), que conecta a diseñadores con clientes. Integra catálogo, carrito, pagos y un panel de administración, todo protegido con un sistema de seguridad de varias capas.

// QUÉ SE CONSTRUYÓ

02

Funcionalidades

  • Registro y autenticación con encriptación multinivel
  • Catálogo dinámico de productos personalizables
  • Carrito de compras que se actualiza en tiempo real
  • Pasarela de pagos simulada para probar el flujo de compra
  • Panel de administración de productos, pedidos y usuarios
03

Arquitectura de seguridad

  • Contraseñas con bcrypt (password_hash)
  • Consultas preparadas contra SQL Injection
  • Protección contra XSS y tokens CSRF
  • Validación en frontend y backend
  • Sesiones seguras con regeneración de ID

Para cada usuario

  • Clientes: catálogo, carrito persistente, pedidos y perfil
  • Administradores: inventario, pedidos, usuarios y promociones
  • Pagos: confirmación automática y comprobantes

// RETOS Y SOLUCIONES

Proteger datos y transacciones

Seguridad en varias capas: encriptación de contraseñas, validación estricta de entradas y consultas preparadas en todo el sistema.

Comprar sin recargar la página

AJAX con jQuery para actualizar el carrito y procesar acciones al instante, con una experiencia mucho más fluida.
