// 01 · LA MISIÓN

La misión

Una tienda en línea para vender servicios y productos gráficos personalizados, como camisetas, cuadernos y termos. El visitante se registra, inicia sesión con su correo o su apodo, explora el catálogo, agrega productos al carrito y puede editar su perfil. Los usuarios se guardan en una base de datos MySQL conectada con PHP, que corre en local con XAMPP.

// QUÉ SE CONSTRUYÓ

02

Funcionalidades

  • Registro e inicio de sesión con correo o apodo
  • Validación de formularios con jQuery
  • Catálogo filtrable con buscador: servicios, productos, camisetas y cuadernos
  • Carrito con contador y total en tiempo real
  • Perfil de usuario editable, guardado en la base de datos
03

Backend y base de datos

  • PHP conectado a MySQL (MariaDB) en XAMPP
  • Tabla de usuarios administrada con phpMyAdmin
  • Sesiones de PHP para recordar al usuario entre páginas
  • Escape de las entradas antes de guardarlas

Lo que le sumaría hoy

  • Contraseñas cifradas con password_hash
  • Consultas preparadas y tokens CSRF
  • Catálogo y pedidos guardados en la base de datos
  • Pasarela de pagos real: el checkout quedó como siguiente paso

// RETOS Y SOLUCIONES

Que la tienda recuerde quién eres

Usé sesiones de PHP: al iniciar sesión se guardan los datos del usuario, y así su nombre y su perfil lo acompañan de la tienda a la configuración.

Editar solo lo que cambia

El formulario de perfil arma la actualización únicamente con los campos que el usuario llenó, para no borrar el resto de sus datos.
